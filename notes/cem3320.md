# CEM3320 2-pole (OB-Xa) model for the E4 2-pole lowpass

Model and fit: `tools/cem3320.py` (plot `notes/cem3320_fit.png`). Status: model only, not on hardware.

## Source circuit
Electric Druid's OB-Xa 2-pole schematic (copy in `../ref/img/obxa2.png`):
- Stage 1: summer (no cap). Inputs: audio, LP feedback from output via 91K, Res-VCA output (pin 1).
- Stages 2, 3: integrators (300p, no local feedback R) → state-variable filter; stage 3 = audio out (LP).
- Resonance: BP (stage 2) via 15µF → 220K → Res VCA, plus a fixed trim path (500K "Res Adjust" + 300K).
- 1N4148 pair (75K/100K into stage 2) limits amplitude so it can oscillate without running away.

Linear model: `H(s) = kL / ((s/ω)² + d·(s/ω) + kL)`, `kL = 100K/91K = 1.10`, `Q = √kL / d`.
Passband stays flat as resonance rises (SVF behaviour, unlike a ladder); the peak grows with Q.
Not reproducible on the E4's linear stages: OTA tanh saturation, diode limiting, self-oscillation.

Reference code consulted: QuadMorphFilter (`TptFilter_Ladder.cpp`, model 12 – a ladder with a 2-pole
tap and tanh input stage; not the OB-Xa SVF topology), DSPFilters (pole/zero → biquad conventions).

## Mapping to EOS
- Pole pair per resonance step, matched-z: `r = e^(−ω0T/2Q)`, `θ = ω0T·√(1−1/4Q²)` →
  `X = 255 + 16·log2(1−r)`, `F = 215 + 32·log2(f_θ / 9824)`.
- Frames: low frame F = 8 (~110 Hz), high frame F = 238 (~16 kHz) in model calibration.
- Resonance law `Q = 0.707·(20/0.707)^(q/127)` → X falls linearly with q.

### Matching FUN_00065E18 constants (realtime resonance path)
| field | stock | CEM fit |
|---|---|---|
| X_low  | 0x84 + (−50·q)>>7 | 0x95 + (−74·q)>>7 |
| F_low  | 0x08 + (−3·q)>>7  | 0x01 + (9·q)>>7 |
| X_high | 0xFF + (−43·q)>>7 | 0xFD + (−61·q)>>7 |
| F_high | 0xCF + q>>2       | 0xE7 + q>>4 |
Fit error ≤ 4 steps in X; F is ~9 steps off at the very lowest resonance (the table is exact).

## Differences from stock E-mu 2-pole
- Stock resonance fades as cutoff rises (Q≈1.5 at the bottom, open/flat at the top); CEM fit is constant-Q.
- Max Q ≈ 18 vs ≈ 12 stock: up to ~6–8 dB more peak. Watch headroom; stock gain tables are kept.
- Both are all-pole; near Nyquist the digital response flattens (an optional zero pair at Nyquist would
  mimic bilinear roll-off but needs the F→Hz calibration confirmed).

## Built: option A (`sysex/EOS470_CEM3320_test.syx`)
- `tools/patch_cem3320.py` checks every original byte, patches, recomputes the checksum.
- RES16 is generated from the patched realtime formula at each step's midpoint, so note-on and
  live-resonance paths agree exactly (shipped table differs from the "exact" table above).
- `tools/emu_fun65e18.py` runs FUN_00065E18 in Unicorn (ColdFire V4e core): stock emulation matches
  the decompiled formula 128/128; patched emulation matches the Python formula 128/128.
- Response of the shipped bytes: `notes/cem3320_patch.png`.

## Patch options (no flash growth)
- **A, data-only:** replace RES16 + the 8 immediates in FUN_00065E18. Affects 2-, 4- and 6-pole lowpass
  (all share them; 4/6-pole become cascaded CEM 2-pole sections).
- **B, 2-pole only:** new 64-byte table for LP2 plus a small change so LP2 stops sharing FUN_00065E18.
  Needs ~100 bytes of verified-free space.
